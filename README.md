# PlayGrid

Free browser games. No downloads. Just play.

## Games

- **Tic-Tac-Toe** — `/games/tic-tac-toe`
  - vs AI (Easy / Hard)
  - 2 Players (same device)
  - Score tracking

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4

## Local

```bash
npm install
npm run dev
```

## Deploy

Connected to Vercel via GitHub `main` branch.
